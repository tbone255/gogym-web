# GoGym — web build

Compiled output only. This repository holds the built web app that
GitHub Pages serves; CI overwrites it on every deploy, so there is
no history here worth reading and pull requests against it will be
discarded.

**The app:** https://tbone255.github.io/gogym-web/

Your training data is stored by your browser, on your device. It is
never uploaded — the app has no server and no account. That also
means it is not shared with the Android app, and clearing your
browser's site data erases it. Use **Settings → Back up
everything** to keep a copy.

Source is kept in a separate private repository.
